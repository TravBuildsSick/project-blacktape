Where the reasoning went

Before this repository went public, every source comment was removed from the tracked code — project convention favors self-documenting code with no inline commentary. Many of those comments weren't throwaway notes: they recorded why a piece of logic exists — a bug that shipped, a real export sample that broke an assumption, a tradeoff between two designs. That reasoning is preserved here instead, one page per source file, so it isn't lost along with the comment syntax.

Each entry below reproduces one removed comment block in full and marks exactly where it used to live, in the form (file, line), referring to the line number in the file as it existed with comments still in place.
